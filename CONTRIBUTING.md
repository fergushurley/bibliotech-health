# Contributing

Use Node 24 and npm workspaces. Keep changes small and run lint, typecheck, tests and build. Maintain exact evidence references and distinguish source evidence from derived memory. Add meaningful tests when changing normalization, matching, memory or permissions. Use only synthetic data in fixtures, issues, screenshots and logs. Keep secrets and `.data/` out of Git. Preserve the MIT license. Provider contract changes require a real schema inspection and explicit verification results, not a silent mock fallback.
